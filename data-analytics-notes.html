📊 1.1 What is Data Analytics?

Definition of Data Analytics

Data Analytics is the process of collecting, cleaning, examining and interpreting data to discover useful information, patterns and insights that support better decision-making.
Simple Meaning: Data Analytics means studying data to understand what happened, why it happened, what may happen in the future and what action should be taken.

Importance of Data Analytics

  • Helps organizations make better decisions.
  • Identifies patterns and trends.
  • Helps understand customers.
  • Improves business performance.
  • Helps identify problems and their causes.
  • Supports forecasting and planning.
  • Helps reduce uncertainty in decision-making.
  • Helps organizations use resources more effectively.
Example: Suppose a company has sales data for five years. By analyzing the data, the company can identify which products sell the most, which months have higher sales and which products are losing demand.

Types of Data Analytics

1. Descriptive Analytics

Answers: "What happened?" It summarizes historical data using reports, tables and charts.

2. Diagnostic Analytics

Answers: "Why did it happen?" It investigates the reasons behind an event or result.

3. Predictive Analytics

Answers: "What is likely to happen?" It uses historical data, patterns and models to forecast future outcomes.

4. Prescriptive Analytics

Answers: "What should we do?" It recommends possible actions based on analysis.

Type Main Question Example
Descriptive What happened? Last month's sales were ₹10 lakh.
Diagnostic Why did it happen? Sales decreased because demand fell.
Predictive What may happen? Sales may increase next month.
Prescriptive What should we do? Increase promotion for the product.
🔄 1.2 Data Analytics Process

The Data Analytics Process is a systematic sequence through which raw data is converted into useful information and insights.

1

Data Collection

Gather relevant data.

2

Data Cleaning

Correct errors and inconsistencies.

3

Data Analysis

Examine data and identify insights.

4

Visualization

Present information using charts and graphs.

5

Decision Making

Use insights to take action.

1. Data Collection

Data Collection is the first step in the analytics process. It involves gathering relevant information from different sources.

2. Data Cleaning

Data Cleaning involves identifying and correcting missing values, duplicate records, incorrect entries and inconsistent formats.

3. Data Analysis

In this stage, data is examined using mathematical, statistical and analytical techniques to identify patterns, relationships and useful information.

4. Data Visualization

Data Visualization presents information using charts, graphs, dashboards and other visual methods.

5. Decision Making

The final objective is to use analytical findings to support effective business and managerial decisions.

💻 2. Introduction to Excel for Data Analytics

What is Microsoft Excel?

Microsoft Excel is a spreadsheet application used to enter, organize, calculate, analyze and present data.

Importance of Excel in Data Analytics

  • Easy data entry and organization.
  • Performs mathematical calculations.
  • Provides many built-in functions.
  • Helps create charts and graphs.
  • Supports data analysis.
  • Useful for small and medium-sized datasets.

Excel Interface and Navigation

Important parts of the Excel interface include the Ribbon, Formula Bar, Name Box, worksheet area, rows, columns and sheet tabs.

Element Meaning / Use
Workbook An Excel file containing worksheets.
Worksheet A spreadsheet page containing rows and columns.
Cell Intersection of a row and column.
Formula Bar Used to enter or edit cell contents and formulas.
Name Box Displays the address of the selected cell.
Ribbon Contains Excel commands and tools.

Workbook, Worksheet and Cell

Workbook: The complete Excel file.

Worksheet: An individual spreadsheet inside a workbook.

Cell: The intersection of a row and a column. Example: A1

🧮 2.3 Basic Excel Functions

SUM Function

The SUM function adds numbers from selected cells or ranges.

=SUM(A1:A5)
Example: If A1:A5 contains 10, 20, 30, 40 and 50, the result will be 150 .

AVERAGE Function

AVERAGE calculates the arithmetic mean of numbers.

=AVERAGE(A1:A5)

COUNT Function

COUNT counts the number of cells containing numeric values.

=COUNT(A1:A10)

MIN Function

MIN returns the smallest value from a selected range.

=MIN(A1:A10)

MAX Function

MAX returns the largest value from a selected range.

=MAX(A1:A10)
Function Purpose Example
SUM Adds values =SUM(A1:A10)
AVERAGE Calculates average =AVERAGE(A1:A10)
COUNT Counts numeric cells =COUNT(A1:A10)
MIN Finds smallest value =MIN(A1:A10)
MAX Finds largest value =MAX(A1:A10)

IF Function

The IF function checks a condition and returns one result if the condition is TRUE and another result if it is FALSE.

=IF(A1>=40,"Pass","Fail")
Example: If a student's marks are 65, the formula will return: Pass

AND Function

AND returns TRUE when all specified conditions are TRUE.

=AND(A1>=40,B1>=40)

OR Function

OR returns TRUE when at least one specified condition is TRUE.

=OR(A1>=40,B1>=40)
Remember:
AND → All conditions should be TRUE.
OR → At least one condition should be TRUE.
IF → Gives different results based on a condition.
🎨 2.4 Data Entry and Formatting

Data Entry

Data Entry means entering information into Excel cells.

Data may include:

  • Names
  • Numbers
  • Dates
  • Addresses
  • Marks
  • Sales figures

Formatting Cells and Data

Formatting changes the appearance of data to make a worksheet clearer and easier to understand.

  • Font style and size
  • Bold and italic
  • Font colour
  • Cell background
  • Borders
  • Alignment
  • Number format
  • Currency format
  • Percentage format
  • Date format

Data Validation

Data Validation is an Excel feature used to control the type of data that users can enter into a cell.
Example: Suppose a cell should contain only marks between 0 and 100. Data Validation can be used to prevent values such as 150 or -20.
