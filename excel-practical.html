📗 1. Excel Basics
Microsoft Excel is a spreadsheet application used for data entry, calculations, data analysis and presentation of information.

Important Excel Terms

Term Meaning
Workbook Complete Excel file.
Worksheet Individual spreadsheet inside a workbook.
Cell Intersection of a row and a column.
Row Horizontal arrangement of cells.
Column Vertical arrangement of cells.
Cell Reference Address of a cell, such as A1 or B5.
🧮 2. Basic Excel Functions

SUM

Adds values from selected cells.

=SUM(B2:B10)

AVERAGE

Calculates the arithmetic average.

=AVERAGE(B2:B10)

COUNT

Counts cells containing numeric values.

=COUNT(B2:B10)

MIN

Finds the smallest numeric value.

=MIN(B2:B10)

MAX

Finds the largest numeric value.

=MAX(B2:B10)
Example: Suppose the marks of five students are:

65, 72, 48, 85, 90

Total: =SUM(A2:A6)
Average: =AVERAGE(A2:A6)
Highest: =MAX(A2:A6)
Lowest: =MIN(A2:A6)
Number of marks: =COUNT(A2:A6)
✅ 3. IF, AND and OR Functions

IF Function

IF checks a condition and returns one result when the condition is TRUE and another result when it is FALSE.

=IF(B2>=40,"Pass","Fail")
Practical Example: If B2 contains 65 marks, Excel will display: Pass

AND Function

AND returns TRUE only when all conditions are TRUE.

=AND(B2>=40,C2>=40)

OR Function

OR returns TRUE when at least one condition is TRUE.

=OR(B2>=40,C2>=40)
Remember:

IF → Decision
AND → All conditions
OR → Any one condition

✔️ 6. Data Validation
Data Validation controls what type of information users are allowed to enter into a cell.

Example 1 — Marks

Suppose marks should be between 0 and 100.

  1. Select the marks cells.
  2. Open the Data tab.
  3. Select Data Validation.
  4. Choose Whole Number.
  5. Set minimum value to 0.
  6. Set maximum value to 100.
